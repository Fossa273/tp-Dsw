## Avances y acuerdos

- El frontend se desplego en Vercel y se configura para consumir la API del
  backend mediante `VITE_API_URL`.
- El backend se desplego en Vercel y utiliza `DATABASE_URL`, `JWT_SECRET` y
  `CORS_ORIGIN` como variables de entorno requeridas.
- La persistencia se conecto a una base MySQL alojada en TiDB Cloud.
- Se incorporo Vitest, jsdom y React Testing Library dentro de `Frontend`.
- Se incorporo Vitest y Supertest dentro de `Backend` para pruebas unitarias
  de reglas de negocio e integracion HTTP.
- Se incorporo Playwright dentro de la carpeta `e2e`, con Chromium como
  navegador principal.
- Se agregaron tests unitarios para el componente `Header`.
- Se agregaron tests end-to-end para verificar el inicio de sesion del
  administrador y su acceso al panel administrativo.
- Los tests unitarios y end-to-end se integraron a GitHub Actions.
